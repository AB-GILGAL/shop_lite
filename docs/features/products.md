# Products Feature

## 1. Overview

The Products feature is responsible for retrieving, displaying, and viewing product information in Shop Lite.

The feature currently supports:

- Product listing
- Product details
- Remote API communication
- Product JSON parsing
- Loading states
- Error states
- Retry handling
- Product image rendering
- Navigation from the product list to product details

 ## 3. Layer Responsibilities

The Products feature follows a layered architecture in which each layer
has a specific responsibility.

### 3.1 Data Layer

The data layer is responsible for communicating with external data sources
and converting external data into application models.

It contains:

- `datasources/`
- `models/`
- `repositories/`

#### `datasources/`

The remote data source communicates directly with the Products API.

File:

```text
data/datasources/product_remote_data_source.dart

Its responsibility is to:

Make HTTP requests to the Products API
Receive API responses
Convert API response data into ProductModel objects

#### `models/`

The model layer represents the structure of product data received from the API.

File:

```text
data/models/product_model.dart

ProductModel:

Extends the domain Product entity
Converts JSON data into Dart objects through fromJson()
Converts product objects back into JSON through toJson()
Handles nested product category data through ProductCategoryModel


#### `repositories/`

The repository implementation coordinates access to product data.

File:

```text
data/repositories/product_repository_impl.dart

It implements the domain repository contract and uses the remote data source
to retrieve product information.

### 3.2 Domain Layer

The domain layer contains the core product concepts and contracts.

It does not directly communicate with the API.

It contains:

entities/
repositories/


#### `entities/`

The Product entity represents a product within the application domain.

File:

domain/entities/product.dart

The entity defines the product data required by the application independently
of how that data is retrieved.

#### `repositories/`

The repository interface defines the contract for accessing product data.

File:

domain/repositories/product_repository.dart

The domain layer depends on this abstraction rather than on the concrete
remote data source.

### 3.3 Presentation Layer

The presentation layer is responsible for displaying product information
and responding to user interaction.

It contains:

controllers/
pages/
widgets/


#### `controllers/`

The controllers manage the state required by the product screens.

Files:

presentation/controllers/product_controller.dart
presentation/controllers/product_details_controller.dart

They use Riverpod to expose asynchronous product data to the UI.

The corresponding .g.dart files are generated files created by Riverpod's
code generation process:

product_controller.g.dart
product_details_controller.g.dart

These generated files should not be manually edited.

#### `pages/`

Pages represent complete product-related screens.

presentation/pages/products_page.dart
presentation/pages/product_details_page.dart

ProductsPage displays the product listing.

ProductDetailsPage displays information about a selected product.

#### `widgets/`

Reusable UI components specific to the Products feature are placed here.

File:

presentation/widgets/product_card.dart

ProductCard is responsible for presenting an individual product in the
product listing.

### 3.4 Providers

The providers directory contains the Riverpod dependency providers required
by the Products feature.

Files:

providers/product_providers.dart
providers/product_providers.g.dart

product_providers.dart defines the providers used to construct and expose
the dependencies required by the Products feature.

The .g.dart file is generated by Riverpod code generation and should not
be manually edited.

### 3.5 Layer Summary
Layer	Responsibility
Data	Retrieves and converts external product data
Domain	Defines product entities and repository contracts
Presentation	Displays products and manages UI state
Providers	Provides dependencies required by the feature
